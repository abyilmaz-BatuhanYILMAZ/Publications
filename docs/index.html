03 — PEER-REVIEWED WORK

From Android malware
to trustworthy AI.

Two co-authored papers in machine learning for security, separate from the newer AI agent experiments.

2026
INTERNATIONAL JOURNAL OF MOBILE COMMUNICATIONS · 28(1)

Classification of malicious android applications by machine learning methods using permission properties

Permission-feature classification with AdaBoost, Random Forest and neural networks. The paper reports 98.4% best accuracy with ANN and the full 117-feature set.

Read official paper / DOI ↗
2022
IJISAE · 10(2)

Classification of Malicious Android Applications Using Naive Bayes and Support Vector Machine Algorithms

Study of Android permission-based malware classification, reporting 92.4% for Naive Bayes and 90.9% for SVM within the paper's own evaluation.
